# 🚀 渠道一：Google AI Studio（最推荐，永久免费额度）

这是目前最稳定、最官方的“白嫖”渠道。Google AI Studio 是给开发者调试 Prompt 的平台，但对普通用户完全开放。

门槛：需要一个 Google 账号 ，以及（你懂的）魔法网络环境

优势：完全免费：Gemini 3 Pro 在这里有非常可观的免费调用额度，普通人一天根本用不完。参数可调：Temperature、Safety Settings 都能调。安全过滤可关闭：关掉后比网页版更“敢说”。多模态支持：直接拖 1GB 视频/PDF，解析速度比网页 Gmail/Docs 集成还快。

使用步骤：

  1. 访问 http://aistudio.google.com (opens new window)
  2. 登录后，点击左上角 Create New → Chat Prompt
  3. 右侧 Model 下拉里选择：Gemini 3 Pro (Experimental)，或 Gemini 3 Pro 001
  4. 开始对话即可

⚠️ 注意：免费版数据可能会用于训练，不要上传公司机密或隐私内容。

怎么搞：
